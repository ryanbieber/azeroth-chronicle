# Cosmic Origins voice auditions

These files are non-production auditions for the first guided-tour passage. Every candidate reads the same unchanged narration so pacing, intelligibility, authority, and naturalness can be compared directly.

The target is an original male chronicler with power, intelligence, warmth, and an ancient sense of scale. The target is not an imitation of a Warcraft character, actor, or performance.

Run `node scripts/generate-voice-auditions.mjs` to reuse existing files and refresh the manifest, or add `--force` to regenerate every candidate. See `manifest.json` for model provenance, direction, hashes, and generation status.

These files are not wired into the application. A chosen direction must be explicitly approved before the production narration is replaced.
