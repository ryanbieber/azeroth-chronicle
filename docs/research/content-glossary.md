# Content Glossary

Use these terms consistently in authored records and review notes.

| Term | Meaning in Azeroth Chronicle |
| --- | --- |
| Era | A reviewed span of in-world history with a stable map state and chronology. A Chronicle volume is not automatically an era. |
| Worldspace | A fictional atlas coordinate space, such as Azeroth, with an explicit local origin and bounds. |
| Map state | The worldspace assets and geometry applicable to a major historical state. |
| Spatial state | An entity's location or geometry during a particular era, including geographic certainty. |
| Event | A sourced historical occurrence that is not modeled through battle playback. |
| Battle | A sourced conflict with combatants, objectives, outcome, certainty, and optional playback phases. |
| Campaign | A sourced grouping of related battles and routes within an era. |
| Route | A time-aware path with explicit geographic certainty; it is not a tactical unit track. |
| Story guide | A reviewed, data-driven route through StoryNodes. |
| Claim | One reviewable assertion about a subject. Claims are kept separate when sources disagree. |
| Source | A work in the research inventory, including its volume or format. |
| Citation | A resolvable location within a Source that supports a Claim or relationship. |
| Relationship | A source-aware edge between records, including causal and non-causal connections. |
| Public summary | Original paraphrase approved for application display; never copied source prose. |

## Status vocabulary

- `placeholder`: unmistakably fictional technical-fixture content.
- `research`: candidate material that has not completed human review.
- `reviewed`: a human lore reviewer has verified the record and its citations.
- `published`: reviewed material approved for inclusion in the public build.

Do not use “canon” as a status. The application reports sources, confidence, disputes, and review state rather than claiming authority.
