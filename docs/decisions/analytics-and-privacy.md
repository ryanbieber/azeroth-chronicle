# Analytics and Privacy Decision

Status: accepted for the MVP on 2026-09-12.

The public MVP ships without analytics, cookies, accounts, fingerprinting, advertising, or third-party telemetry. The static host may retain ordinary request logs under its own operational policy, but the application does not add identifiers or send behavioral events.

Reconsider analytics only when a named product question cannot be answered through voluntary feedback or privacy-preserving aggregate host metrics. Any future analytics proposal must document the event list, retention, processor, consent requirements, user-facing notice, and a no-tracking path before implementation.
